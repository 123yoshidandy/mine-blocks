# MINE BLOCKS

## ゲーム概要

MINE BLOCKSは、盤面の数字と赤いマス（マイン）をヒントに、ピースを盤面に置いて埋めていくパズルゲームです。斜線以外のマスをすべて埋めることができたらクリアです。

## ゲームのルール

1. **目的**: 斜線以外のすべてのマスにピースを置いて、盤面を埋める
2. **盤面**: 数字のマス、赤いマス（マイン）、斜線のマス（ピースを置けない）でできている
3. **ピース**: 置き場に8個のピースがあり、そのうち6個を使う（残りの2個は使わない）
4. **数字**: 数字は「そのマスを覆うピースが、赤いマスをいくつ覆うか」を表す
5. **置ける条件**: ピースが覆う数字が、すべて「そのピースが覆う赤いマスの数」と同じときだけ置ける
   - 例: 赤いマスを1個覆うピースは、「1」のマスしか覆えない
   - 条件を満たしていれば、想定した解とは違う場所にも置ける
6. **やり直し**: 置いたピースは外したり、別の場所に動かしたりできる

ゲーム内の「？」ボタンから、アニメーションで遊び方を確認できます。

## 操作方法

### PC
- ピースをドラッグ＆ドロップして盤面に置く（ピースをクリックで選び、盤面のマスをクリックしても置ける）
- 置こうとしている位置にはプレビューが表示され、置けない位置では赤くなる
- 置いたピースをクリックすると外れて置き場に戻る

### スマートフォン
- ピースをタッチしたまま盤面までスワイプし、指を離して置く（ピースをタップで選び、盤面のマスをタップしても置ける）
- 置いたピースをタップすると外れて置き場に戻る
- 置いたピースをスワイプすると、別の場所に動かせる

## モード

- **エンドレス**: 1問ずつ自分のペースで解く（ページを開いたときはこのモード）
- **チャレンジ**: トップ画面の「チャレンジ」で開始。持ち時間60秒でスタートし、1問解くごとに20秒加算。残った時間は次の問題に持ち越され、時間切れまでに何問解けるかを競う。途中でやめるときは、左上のロゴでトップ画面に戻る
- **降参**: 解けないときは上部の旗ボタンで降参すると、想定解が表示されて次の問題に進める。チャレンジ中に降参するとタイムアップと同じくチャレンジが終わり、解いた数と最後の問題の想定解が表示される
- **オンライン対戦**: トップ画面の「オンライン対戦」から。2〜4人で同じ問題を同時に解き、一番早く解いた人がその問題の勝ち。先に決めた勝ち数（1〜5勝）に届いた人が優勝

## トップ画面

開いたときにトップ画面が出て、エンドレス・チャレンジ・オンライン対戦を選べる。遊んでいる途中でも、左上のロゴか右上の家のボタンを押すとトップ画面に戻る（チャレンジ中はそのまま終了し、対戦中は確認してから退出する）。オンライン対戦の招待URLで開いたときは、トップ画面を出さずに参加画面に進む。

## オンライン対戦

1. トップ画面の「オンライン対戦」を押し、名前を入れて「部屋を作る」を押す
2. 「招待URLを共有」で友人にURLを送る（友人は開いて名前を入れ、「参加する」を押す。部屋番号（数字4桁）でも参加できる）
3. 部屋を作った人が勝ち数を選び、「対戦開始」を押す
4. 3秒のカウントダウンのあと、全員に同じ問題が出る。一番早く解いた人がその問題の勝ち。降参した人はその問題では勝てない（全員降参なら勝者なし）
5. 問題が終わると、勝った人・タイム・全員の勝ち数・想定解が表示される。そのまま8秒のカウントダウンのあと、全員同時に次の問題が始まる（ボタンを押す必要はない）
6. 誰かが勝ち数に届いたら試合終了。全員が「再戦する」を押すと、同じメンバー・同じ勝ち数で次の試合が始まる（退出した人は待たない）

- 接続が切れても、同じ端末なら同じ席に戻れる（対戦中に戻った場合、その問題は最初からやり直し）
- 部屋は最後の操作から1日で自動的に消える

## 問題と共有

- エンドレスとチャレンジの問題は、毎回ランダムに作られる
- オンライン対戦では、サーバーが配る問題番号から全員が同じ問題を作る
- トップ画面の「共有する」で、ゲームのページのURLを送って友達を誘える

## 技術詳細（開発者向け）

### パズル生成
- 乱数は問題番号をシードにした mulberry32 を使い、どのブラウザでも同じ問題になる
- ピースは3〜6マスで、2×3（縦長なら3×2）の枠に収まる形だけを使う（1×2のピースは別解の原因になるため使わない。3×3の枠が必要な大きなピースや、同じ形のピースは作り直す）
- ピースのマイン数はマス数の1/3（最低1個）〜マス数−1。数字が「1」に偏らず、マインでないマスが必ず1つ残る
- 8個のうち6個のピースを、互いに接する辺が多くなるように7×7の範囲に並べて想定解を作る
- 想定解が収まる最小の長方形を盤面とし、想定解で使わないマスは斜線（置けないマス）になる

### ファイル構成
- `index.html` / `style.css`: 画面とデザイン
- `js/random.js`: シード付き乱数（ランダムな問題番号の作成）
- `js/game-state.js`: ゲームの状態、画面要素、タイマー
- `js/block.js`: ピースの生成と描画
- `js/solution.js`: 想定解と盤面の生成
- `js/board.js`: 盤面の描画、ピースの配置判定・配置・取り外し、クリア判定
- `js/effects.js`: クリアの演出（盤面の波と紙吹雪）
- `js/top.js`: トップ画面（遊び方を選ぶ。ロゴを押すと戻る）
- `js/interaction.js`: ドラッグ＆ドロップ、タッチ操作
- `js/ui.js`: ボタン、共有、配置プレビュー
- `js/challenge.js`: チャレンジモード
- `js/hint.js`: 遊び方（アニメーションでの説明）
- `js/surrender.js`: 降参と想定解の表示
- `js/online-config.js`: オンライン対戦のサーバーの URL
- `js/online.js`: オンライン対戦の画面（参加画面、ロビー、カウントダウン、対戦中のバー、結果画面）
- `js/netplay/`: netplay-kit からコピーした、オンライン対戦の通信の共通部品（接続・再接続・参加情報の保存・ping・時計のずれの補正・招待URL）
- `server/`: オンライン対戦のサーバー
  - `src/game-definition.js`: 対戦の中身（問題番号と開始時刻の配布、解けた／降参の受け付け、勝敗、勝ち数の設定）
  - `src/handler.js`: Lambda の入口
  - `netplay/`: netplay-kit からコピーした、部屋の仕組みの共通部品（作成・参加・再接続・保存・送信・テストの道具）
  - `dev-server.js`: 手元で試すためのテスト用サーバー
  - `template.yaml`: AWS SAM のテンプレート
- `netplay-kit.lock.json`: コピーした netplay-kit の版と、各ファイルのハッシュ
- `test/`: 対戦の中身のテスト（Vitest）
- `js/main.js`: 初期化と問題の生成

### オンライン対戦のしくみ
- 部屋の仕組み（作成・参加・再接続・保存・送信）は、ほかのゲームと共通の netplay-kit を使う。`js/netplay/` と `server/netplay/` は手で直さず、netplay-kit で直してから `node ../netplay-kit/scripts/sync.mjs .` で同期する（`sync.mjs check .` で、手で直されていないか確かめられる）
- 問題は問題番号から各端末で作るので、サーバーは問題番号・開始時刻・結果（解けた／降参とタイム）だけを扱う
- 開始時刻とタイムはサーバーの時計で決める。端末にはサーバーの時刻も送り、カウントダウンの終わりを端末の時計に合わせる
- 解けたかどうかは端末からの通知を信用する（友人どうしの対戦を想定）

## 開発

必要なもの：Node.js 22 以上、Python 3（画面を手元で配信するため）

```bash
npm install

# 画面を手元で配信して http://localhost:8089 を開く
python3 -m http.server 8089

# テスト
npm test
```

### オンライン対戦を手元で試す

AWS を使わずに、同じ処理のテスト用サーバーを手元で動かせます。画面を `localhost` で開くと、自動でこのサーバーにつながります。

```bash
npm run dev:server   # ws://localhost:8787
```

URLに `?server=wss://...` を付けると、接続先のサーバーを変えられます。1台で2人分試すときは、`localhost` と `127.0.0.1` のように別のアドレスで開くと、参加情報が混ざりません。

## サーバー（AWS）

API Gateway（WebSocket）・Lambda・DynamoDB を AWS SAM で作ります（東京リージョン、スタック名 `mine-blocks-online`）。

- 部屋は最後の操作から1日、ログは7日で自動的に消える
- 想定外のアクセスに備えて、受け付けるリクエストの数に上限を設けている

### デプロイ

AWS SAM CLI と AWS CLI が必要です。プロフィールは環境変数で渡します。

```bash
AWS_PROFILE=<プロフィール名> npm run deploy:server
```

初めてデプロイしたときは、出力される `WebSocketUrl` を `js/online-config.js` の `ONLINE_DEPLOYED_SERVER_URL` に書きます。画面は main ブランチに push すると GitHub Pages に反映されます。
