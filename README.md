# MINE BLOCKS

## ゲーム概要

MINE BLOCKSは、数字をヒントにしながら、与えられたブロックを盤面に置いていくパズルゲームです。盤面の数字は周辺のマイン（地雷）の数を表しており、ブロックをうまく配置して盤面を埋めることができたらクリアとなります。

## ゲームのルール

1. **目的**: 配置可能なすべてのマスにブロックを置いて盤面を埋める
2. **盤面**: 6×6のマス目で構成され、一部のマスは配置不可（灰色で表示）
3. **ブロック**: 6つのブロックが提供されますが、すべてのブロックを使う必要はありません
4. **マイン**: 各ブロックには1～4個のマイン（赤いマス）が含まれています
5. **数字**: 盤面の数字は、そのマスに置かれるブロックに含まれるマインの数を示しています
6. **スコア**: クリア時間が短いほど高得点になります（300点から経過秒数を引いた点数）

## 操作方法

### PC
- ブロックをクリックして選択
- 選択したブロックをドラッグ＆ドロップで配置
- 配置予定位置にはプレビューが表示され、マインは赤く点滅します

### スマートフォン
- ブロックをタップして選択
- 画面上をスワイプしてブロックを移動
- 配置したい位置で指を離すとブロックが配置されます

## ゲーム機能

- **新しいゲーム**: いつでも新しいパズルを開始できます
- **ヒント**: ゲームのヒントを表示します
- **クリア表示**: パズルをクリアすると、経過時間と獲得スコアが表示されます
- **統計情報**: スコアとクリア回数が画面上部に表示されます

## 技術詳細（開発者向け）

### コア機能
- **パズル生成アルゴリズム**: ブロックがすべて連結する解答を自動生成
- **マイン配置**: ブロックごとにランダムに1～4個のマインを配置
- **タッチ対応**: モバイルデバイスでのスワイプ操作に対応
- **レスポンシブデザイン**: 画面サイズに応じたレイアウト調整

### 実装のポイント
- ブロックは必ず縦横で連結するように配置され、「飛び石」配置は不可
- 実際に解けるのは4つのブロックだけですが、ダミーとして2つ追加しています
- クリア判定は「すべてのブロックを使う」ではなく「配置可能なすべてのマスを埋める」
- 数字とマインの関係を正しく理解することがパズル解決の鍵です

## 利用方法
1. index.htmlをブラウザで開く
2. 「新しいゲーム」ボタンでスタート
3. ブロックを選択して配置し、パズルを解いていく
